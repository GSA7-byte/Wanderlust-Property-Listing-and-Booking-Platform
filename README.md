# Wanderlust Property Listing and Booking Platform

A full-stack web application that enables users to list, discover, and book vacation properties from around the world. Wanderlust provides seamless property management, intuitive booking workflows, rich image galleries, and location-based search—all with a secure authentication system and scalable cloud database. Built with Node.js, Express, MongoDB Atlas, and EJS.

## 🚀 Live Demo

[Access the Live App on Render](https://wanderlust-property-listing-and-booking.onrender.com)

---

**Features:**
- User registration and authentication
- Add, edit, or delete property listings
- Book properties and leave reviews
- Check price after taxes
- Interactive map with custom markers and automated geocoding for property locations (Mapbox).
- Responsive design for mobile and desktop
- Cloud database integration (MongoDB Atlas)
